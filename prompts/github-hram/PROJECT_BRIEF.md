# github-hram

## Роль

Публичная AI-собранная витрина инженерных проектов Евгения Храмова. Продукт объединяет интерактивную карту проектов, отдельные страницы кейсов, карьерный контекст и технический радар в одном статическом GitHub Pages сайте.

## Одной строкой

Портфолио-сайт, который превращает набор AI-построенных систем в понятный, проверяемый и краулабельный продукт.

## Задача, которую решает

Обычный список репозиториев показывает артефакты, но не объясняет масштаб, метод и качество работы. `github-hram` связывает проекты в единую систему: посетитель видит карту, открывает подробный кейс, читает факты и понимает, как ИИ использовался в разработке.

## Что это

- GitHub Pages сайт на Jekyll с минимальной темой и статическими HTML-витринами.
- Интерактивный `project-galaxy.html` с узлами, связями, фильтрами и карточками проектов.
- 12 страниц проектов с метаданными, JSON-LD, описанием метода, фактами и AI-трейсом.
- Карьерные документы и Tech Radar как контекст, в который встроена галактика.

## Что демонстрирует

- **Продуктовое мышление:** AI-результаты оформлены как самостоятельный пользовательский продукт, а не как папка ссылок.
- **Информационная архитектура:** карта, карточка и подробная страница дают три уровня глубины без потери навигации.
- **Публичная инженерная гигиена:** статический HTML, canonical, Open Graph, JSON-LD, sitemap и краулабельный контент.
- **Переиспользование:** единый шаблон страницы позволяет описывать новые проекты с одинаковым уровнем качества.

## Стек и архитектура

- Jekyll и Just the Docs для основного сайта.
- Статические HTML-страницы для проектной витрины.
- Vanilla JavaScript и SVG для интерактивной карты.
- JSON-LD, Open Graph, canonical и sitemap для поисковой индексации.
- Yandex.Metrika для измерения переходов и вовлечения.

## След AI-процесса

Структура галактики, шаблон страниц, тексты и технические метаданные собирались через AI-агентов на основе контекстных файлов и критериев публикации. Человек задавал модель продукта, проверял публичную безопасность фактов и принимал итоговые изменения через git-коммиты.

## Ограничения публичной версии

- Не публиковать приватные репозитории, внутренние адреса, работодателей и чувствительные данные.
- Показывать метод и проверяемые метрики, но не раскрывать внутреннюю инфраструктуру проектов.
- Контент страницы должен оставаться статическим и доступным без выполнения JavaScript.

## Критерии готовности

- Узел `github-hram` есть в графе и списке проектов.
- Карточка узла ведёт на `projects/github-hram.html`.
- Страница содержит корректные SEO-метаданные, JSON-LD, AI-трейс и обратную ссылку на галактику.
- Бриф хранится в `prompts/`, исключённом из публичной сборки Jekyll.
