# allure-testops-mcp

## Роль

Standalone MCP-сервер, сделанный для коллеги-тестировщицы Ани и её работы с тестовой документацией в Allure TestOps: находить и изменять тест-кейсы, сценарии, issue-связи и пользовательские поля.

## Одной строкой

MCP-адаптер, который превращает операции Allure TestOps над тест-кейсами в набор типизированных инструментов агента.

## Задача, которую решает

Без интеграции агенту приходится переключаться в UI или вручную повторять HTTP-запросы к системе управления тестами. Сервер даёт единый stdio-контракт для поиска, чтения, создания, удаления и обновления тестовых артефактов.

## Что это

- Локальный Node.js MCP-сервер с подключением через stdio.
- 10 инструментов для test cases, scenario steps, issue links и custom fields.
- API-клиент с OAuth token exchange, кэшированием access token, таймаутом и обработкой ошибок.
- Нормализация ответов API в компактные структуры, удобные для агента.
- Опциональная запись ответов инструментов в timestamped JSON-артефакты.

## Что демонстрирует

- Интеграционное мышление: одна обёртка покрывает связанные сущности тест-менеджмента.
- Контроль качества: агент получает возможность поддерживать тестовую документацию рядом с изменениями продукта.
- Надёжность границы системы: конфигурация, токены, редиректы, HTTP-ошибки и некорректный JSON обрабатываются явно.
- Проверяемость: MCP-контракт и клиент покрыты автоматическими тестами с мокированными HTTP-запросами.

## Стек и архитектура

- Node.js, JavaScript, npm.
- `@modelcontextprotocol/sdk` и stdio transport.
- Неблокирующий HTTP/HTTPS-клиент без тяжёлого фреймворка.
- OAuth token exchange через API token, кэширование access token до истечения срока.
- Node test runner, изолированные mock HTTP-тесты и опциональные JSON-артефакты ответов.
