# android-ui-renderer-mcp

## Роль

Локальный MCP-сервер для AI-агентов, которые разрабатывают Android XML/View-интерфейсы. Проект даёт агенту быстрый цикл: изменить layout → получить PNG и дерево View → проверить геометрию → повторить.

## Одной строкой

MCP-инструмент, который рендерит Android XML через Robolectric и возвращает снимок экрана, иерархию View и точные границы без запуска эмулятора.

## Задача, которую решает

Обычная проверка Android UI требует Layout Preview, эмулятора, устройства или тяжёлых screenshot-тестов. Агенту нужен быстрый и машинно-читаемый feedback loop: изображение для визуальной проверки, bounds для измерений и диагностика типовых проблем раскладки.

## Что это

- Локальный MCP-сервер на Kotlin/JVM с stdio-подключением.
- Рендеринг XML/View через Robolectric в отдельном worker-процессе.
- `render_layout` возвращает PNG, View Tree, `renderId` и timings.
- `get_view_tree` и `inspect_view` позволяют исследовать результат без повторного рендера.
- Конфигурация темы, ориентации, density, locale, night mode, font scale и fixture-данных.

## Что демонстрирует

- Быстрый feedback loop для AI-разработки интерфейсов.
- Контроль качества через измеряемую геометрию, а не только визуальное впечатление.
- Корректную работу с изменяемыми исходниками: fingerprint, инкрементальная сборка и перезапуск устаревшего worker.
- Осознанные границы MVP: Android XML/View вместо обещания заменить реальное устройство.

## Стек и архитектура

- Kotlin/JVM, Gradle, Kotlin serialization.
- MCP stdio transport.
- Robolectric worker для Activity, inflate, measure/layout/draw.
- Persistent MCP server и reloadable worker: worker переиспользуется только пока совпадает source/build generation.
- Временная Gradle/Robolectric probe-задача для рендера в проекте пользователя без постоянной зависимости и тестовых исходников.

## След AI-процесса

RFC в репозитории фиксирует решение, границы MVP, контракт MCP-инструментов, формат View Tree и инвариант свежести worker. Реализация развивалась короткими проверяемыми шагами: от валидаторов и fingerprint до fixture, геометрии, timings и production inflation configuration.

## Публичная витрина

Не публиковать локальные пути, внутренние рабочие каталоги и детали конкретных Android-проектов-потребителей. Показывать архитектуру, API, измеримые свойства и границы применимости.
